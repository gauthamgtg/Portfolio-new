# Gautham M — Portfolio

An award-winning-style personal portfolio for **Gautham M, Data Analyst** — built with
Next.js, TypeScript, Tailwind CSS, and Framer Motion. Dark glassmorphism aesthetic with
glowing neon accents, scroll-reveal animations, animated count-up metrics, 3D tilt
project cards, and a magnetic, responsive UI.

## Tech stack

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** for styling
- **Framer Motion** for animation
- **lucide-react** for icons

## Sections

Hero · Impact metrics · About · Experience timeline · Skills & analytical techniques ·
Key projects · GitHub repositories (original work only) · Education · Contact.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
```

## Production build

```bash
npm run build
npm run start
```

## Editing content

All content lives in a single typed file: [`lib/data.ts`](./lib/data.ts) — update profile,
metrics, experience, skills, projects, repos, education, and contact details there.

## Deploy

Vercel-ready. Push the repo and import it at [vercel.com](https://vercel.com), or run
`vercel` from the project root.
